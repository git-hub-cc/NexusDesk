# NoteIDE 产品功能说明文档

**产品定位**：一款面向开发者与重度知识工作者的 IDE 级本地笔记软件。
**核心设计语言**：严格对标 IntelliJ IDEA（包含 UI 布局、交互逻辑、全局快捷键与工具窗口概念）。
**底层架构**：Tauri + Rust + React + SQLite。

---

## 一、 界面与布局系统 (Workspace)

### 1. 基础布局
采用经典的 IDE 三栏/四栏布局，各面板支持拖拽调整大小、折叠与展开。
*   **左侧边栏 (Left Tool Window)**：默认承载目录树视图。
*   **主工作区 (Editor Area)**：承载多标签页编辑器，支持左右/上下分屏。
*   **底部/右侧边栏 (Bottom/Right Tool Window)**：承载 Git 面板、文件关联视图、全局搜索结果等。

### 2. 标签页管理 (Tabs)
*   支持同时打开多个文件，顶部以 Tab 形式排列。
*   支持拖拽 Tab 进行排序或拖拽至屏幕边缘触发分屏（Split Right / Split Down）。
*   支持固定标签页 (Pin Tab)。

### 3. 全局快捷键
严格映射 IntelliJ IDEA 默认快捷键体系：
*   `Double Shift`：全局搜索（Search Everywhere）。
*   `Ctrl + E` / `Cmd + E`：最近打开的文件列表。
*   `Alt + 1` / `Cmd + 1`：显隐左侧目录树。
*   `Ctrl + B` / `Cmd + B`：跳转到双链引用位置。

---

## 二、 目录与文件管理 (Directory System)

同一份本地物理文件，支持通过切换视图模式呈现不同的目录树结构。

### 1. 物理模式 (Project View)
*   **映射规则**：与操作系统本地文件系统 1:1 严格映射。
*   **功能**：真实文件夹的创建、重命名、移动、删除。

### 2. 性质模式 (Logical View)
*   **映射规则**：基于文件内部元数据（Frontmatter/Tags）动态生成的虚拟目录树（如：灵感、问题、工具、模板）。
*   **核心交互 (拖拽重构)**：
    *   用户将文件从“物理模式”拖入“性质模式”的特定目录，或在“性质模式”不同目录间拖拽。
    *   **系统行为**：不改变文件的物理存储路径，仅自动修改该文件内部的元数据（如将 `type: inspiration` 修改为 `type: tool`），视图实时刷新。

### 3. 异步批量操作
*   **场景**：复制/粘贴包含大量文件的目录。
*   **系统行为**：在后台异步执行 I/O 操作与索引重建，底部状态栏显示进度条（Indexing...），不阻塞主界面 UI 交互。

## 三、 编辑器与知识链接 (Editor & Linking)

### 1. 编辑器基础
*   **模式切换**：支持 Markdown 源码编辑模式与所见即所得预览模式的无缝切换。
*   **大文件支持**：基于 CodeMirror 6，支持超长文本的流畅编辑。

### 2. 拖拽式双链 (核心创新交互)
*   **触发**：在编辑器 A 中输入 `[[` 触发链接联想状态。
*   **交互**：鼠标指针状态改变，用户按住鼠标左键，拖拽指向分屏状态下的编辑器 B 中的特定标题或段落，松开鼠标。
*   **结果**：编辑器 A 自动生成精准的锚点链接（如 `[[文件名#标题名称]]`）。

### 3. 关联视图 (Relational View)
*   **位置**：作为独立的 Tool Window（默认在右侧或底部）。
*   **内容**：
    *   **反向链接 (Backlinks)**：显示所有引用了当前文件的外部文件及具体上下文段落。
    *   **正向链接 (Forward links)**：显示当前文件引用的所有外部文件。
*   **交互**：树状结构展示，点击节点直接跳转至对应文件的具体行。

---

## 四、 版本控制 (Git Integration)

原生集成 Git 工作流，底层调用 `git2-rs`，无需依赖系统命令行。

### 1. 提交面板 (Commit Tool Window)
*   **视图**：区分 Staged（已暂存）和 Unstaged（未暂存）文件列表。
*   **Diff 预览**：点击文件，主工作区打开 Diff 视图，高亮显示增删改的行。
*   **操作**：提供 Commit Message 输入框，支持 Commit、Commit & Push 操作。

### 2. 历史面板 (Log Tool Window)
*   **视图**：可视化展示 Git 提交历史树（分支合并轨迹）。
*   **功能**：查看历史 Commit 详情、回滚特定版本、分支切换。

## 五、 后续规划 (Roadmap)

以下功能不在 MVP（最小可行性产品）阶段开发，作为后续迭代或插件化扩展：
1.  **多格式预览**：常见办公软件格式（PDF, Word, Excel）、图片、音视频的本地预览。
2.  **轻量级图像处理**：内置图片裁剪、标注等简单编辑功能。
3.  **可视化视图**：基于 Markdown 节点自动生成思维导图。
4.  **白板模式**：支持自由排版、手绘与卡片连线的无限画布。
