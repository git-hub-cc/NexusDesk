## 笔记软件
目录的显示方式存在多种方式，借鉴 IntelliJ 的项目呈现模式，同一份物理数据可以投射出完全不同的目录树
例如
1. 以实现目标的所有内容，这也是真实存储，这与project形式管理项目一致
2. 按内容的性质进行规划，灵感，问题，工具，模板等，将真实文件进行聚合

未特殊说明的内容都参考 IntelliJ，交互逻辑、UI 设计风格、设计语言（如组件样式、配色、图标隐喻）以及**全局快捷键**，均严格对标 **IntelliJ IDEA**。

功能
1. 左侧为目录树，右侧为编辑器。目录树支持切换不同模式，用户可以在性质模式，新增目录，将里程碑的文件拖拽进性质模式的相应目录。例如原本在里程碑模式不同目录的文件放入性质模式的同个目录。
2. 编辑器上方有标签页，支持同时显示两个标签页，编辑器支持切换markdown 编辑或预览
2. 编辑器内容如果关联其它文件，会有一个额外的视图，显示当前文件关联的所有文件。
3. 文件关联的方式类似于obsidian的双链，用户输入简单字符后，支持点击拖拽指向另一标签页的某个标题。
4. 用户复制文件或目录，选择目录进行粘贴时，自动将文件或目录复制进自定位置，这里可能复制很多文件，考虑好性能
5. 支持使用git上传，与IntelliJ一样的所有功能，包含commit区域，log区域等
